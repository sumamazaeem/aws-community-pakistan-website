Adding a group

Copy content/student-builder-groups/_TEMPLATE.yml to content/student-builder-groups/<slug>.yml, fill it in, and open a pull request. The slug must match the filename, every URL must be https://, and parent_user_group must name a real group in content/user-groups/ — the build fails if it does not, so a typo cannot ship a dead link.
